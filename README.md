# TRAP AI

Mobile-first PWA interface for the TRAP AI market-intelligence project.

## Current build
- Market sentiment dashboard
- Scanner
- Option Opportunity view
- Trap Radar
- Historical backtest interface
- PWA manifest
- GitHub Pages deployment workflow

## Important
This first deployment is the application shell/UI. It does **not** claim to provide live market signals yet. Live NSE/global market feeds, news ingestion, options-chain data, macro feeds, storage and the timestamp-safe backtest engine still need to be connected on a secure backend.

The architecture is intentionally designed so those services can be added without rebuilding the mobile UI.
